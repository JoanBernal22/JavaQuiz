# JAVAQUIZ - Concurso de preguntas sobre Java

## 1. Descripción del proyecto

JavaQuiz es una aplicación de consola desarrollada en Java que consiste en un concurso de seis preguntas sobre conceptos básicos del lenguaje Java.

El usuario debe responder a cada pregunta seleccionando una de las tres opciones disponibles (A, B o C). Al finalizar el concurso, el programa muestra el número total de respuestas correctas.

## 2. Características

- Seis preguntas sobre lo aprendido hasta ahora en Java.
- Tres opciones de respuesta por pregunta.
- Comprobación automática de las respuestas.
- Contador de aciertos compartido.
- Resultado final con el número de respuestas correctas.
- Entrada de respuestas mediante Scanner.

## 3. Reparto del trabajo

El proyecto se ha desarrollado por parejas:

**Integrante A:**
- Desarrollo de las preguntas 1, 2 y 3.
- Preguntas relacionadas con tipos de datos, arrays y salida por pantalla.

**Integrante B:**
- Desarrollo de las preguntas 4, 5 y 6.
- Preguntas relacionadas con condicionales, bucles y String.
- Implementación del resultado final.
- Cierre del Scanner.

## 4. Tecnologías utilizadas

- Java.
- Visual Studio Code.
- Git.
- GitHub.

## 5. Cómo ejecutar el programa

1. Descargar o clonar el repositorio de GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Comprobar que Java está instalado.
4. Abrir el archivo `JavaQuiz.java`.
5. Ejecutar el programa desde Visual Studio Code.

También se puede ejecutar desde el terminal:

```bash
javac JavaQuiz.java
java JavaQuiz
```

## 6. Funcionamiento

Al iniciar el programa aparece el título JAVAQUIZ y comienzan las seis preguntas.

El usuario introduce su respuesta escribiendo A, B o C.

El programa indica si la respuesta es correcta o incorrecta y suma un punto al contador cuando se acierta.

Al finalizar, muestra el total de respuestas correctas.

## 7. Archivos del repositorio
